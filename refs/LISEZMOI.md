# Références

Déposer ici les newsletters liftfoils.com reçues par mail, pour servir de
modèle. Trois formats acceptés, par ordre d'utilité :

1. **`.eml`** — le mieux. Gmail : ouvrir le mail, menu `⋮` en haut à droite du
   message, **Télécharger le message**. Donne le HTML exact, les couleurs, la
   structure et les URL des images.
2. **`.txt`** — Gmail : `⋮` → **Afficher l'original** → **Télécharger l'original**.
   Équivalent au `.eml`.
3. **`.png` / `.jpg`** — captures d'écran. Utile pour la direction visuelle,
   mais je perds le HTML et les images sources.
